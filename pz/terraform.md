# Структура проекта в части реализуемой с помощью Terraform

Файлы, необходимые для развертывания базовой инфраструктуры с помощью Terraform, находятся в соответствующей [директории](../terraform/)

---

Файлы и директории не выкладываемые в публичный (удаленный) репозиторий:

- скрытая директория `/.terraform` с кэшем (системные и скачанные извне файлы)

- системный файл `terraform.tfstate` с текущим состоянием всего проекта

- системный файл `terraform.tfstate.backup` резервная копия файла с состоянием проекта

- системный файл `terraform.tfvars` содержит переменные с "чувствительными" значениями

---

Файлы и директории выложенные в публичный (удаленный) репозиторий:

- системный файл [terrafom.lock.hcl](../terraform/.terraform.lock.hcl) для фиксации зависимостей проекта

- файл [cloud-init.yaml](../terraform/cloud-init.yaml) скрипт первичной настройки (provisioning) виртуальной машины, срабатывает ровно один раз при самом первом запуске системы, содержит данные, необходимые для доступа к ВМ по SSH

- файл [providers.tf](../terraform/provider.tf) с описанием провайдеров, использующихся в проекте

- файл [variables.tf](../terraform/variables.tf) с описанием переменных, используемых в проекте

- файл [vms.tf](../terraform/vms.tf) с описанием ресурсов (виртуальных машин), используемых в проекте, также описано формирование файла hosts.ini, используемого на этапе развертывания с использованием Ansible

- файл [network.tf](../terraform/network.tf) содержит описание сетей и групп безопасности, используемых в проекте

- файл [postgres.tf](../terraform/postgres.tf) описывает создание кластера PostgreSQL, пользователя admin и базы данных для Prometheus, также формируется файл с входными данными, используемыми на этапе развертывания с использованием Ansible

- файл [ddns.tf](../terraform/ddns.tf) содержит описание динамического обновления ip-адреса домена в NoIp в зависимости от присвоенного в Yandex Cloud при создании ресурса Application Load Balancer, пока, по непонятной причине, не удалось добиться обновления адреса, возможно из-за ограничений для бесплатного тарифа

- файл [alb.tf](../terraform/alb.tf) описывающий логику работы балансировщика при приеме внешнего трафика
