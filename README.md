# Курсовая работа по профессии "DevOps-инженер с нуля"

### *Выполнил студент группы FOPS-41* - **Муравский Артем**

Разработка выполнена в соответствии с [заданием](https://github.com/netology-code/fops-sysadm-diplom/blob/main/README.md)

Основные технические решения:

- проект реализован с использованием сервисов облачного провайдера Yandex Cloud

- для развертывания и настройки базовой инфраструктуры используется Hashicorp Terraform

- для установки, развертывания и конфигурирования сервисов используется Ansible

- из-за возникновения различных проблем с доступностью пакетов, сервисы (кроме nginx) разворачиваются на базе Docker контейнеров

- для получения доменного имени используется сервис [NoIp](https://www.noip.com)
